# AlloyDecrafting
This mod adds recipes to the Smelter that allow you to decraft Alloys with one of their Ingot and one Crystal Shard.
This mod needs to be on both the Client and the Server to work properly.  
This mod requires that you also have https://github.com/CG-Nik/CustomRecipesAPI downloaded to work properly.  

These recipes are unlocked with the gem that unlocks the Alloy's recipe.  
Each recipe yields the components for the cheapest of its recipes, as to prevent duping.  

This is an unofficial, fan-made mod for A Township Tale. This mod is not affiliated with or endorsed by the owners or developers of A Township Tale.  

### Downloading
- Download AlloyDecrafting.zip off of the latest release.
- Extract AlloyDecrafting.zip and place the resulting AlloyDecrafting folder into your mods folder.
- Do NOT place the contents of the AlloyDecrafting folder into the Mods folder, place the AlloyDecrafting folder directly into the Mods folder.
